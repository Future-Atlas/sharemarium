# Sharemarium 法務文書改定履歴

法務文書を変更するときは、文書ごとに改定日、変更後のバージョン及び変更概要を追記する。

## バージョン規則

各法務文書は、他の文書とは独立して `MAJOR.MINOR.PATCH` の3桁で管理する。変更した文章量ではなく、利用者の権利義務及び制度への影響で判定する。

- `PATCH`（3桁目）：意味や権利義務を変えない修正。誤字、表現整理又は意味を変えない明確化を含む。例：`1.0.0 → 1.0.1`
- `MINOR`（2桁目）：実質的だが根本的ではない変更。機能、手続、取得情報又は利用者ができる操作の追加若しくは変更を含む。更新時はPATCHを`0`へ戻す。例：`1.0.4 → 1.1.0`
- `MAJOR`（1桁目）：利用条件又は制度の根本的・非互換的な変更。更新時はMINORとPATCHを`0`へ戻す。例：`1.4.7 → 2.0.0`

変更した章、条又は文書の数だけでは判定しない。一つの文書だけでも根本的な変更であればMAJORとし、複数文書を修正しても意味や権利義務を変えなければ各文書のPATCHとする。影響を受けない文書のバージョンは変更しない。

同意バンドルのバージョンは、利用者が確認済みの文書一式を識別するための技術的な番号であり、個別文書のバージョンとは別に管理する。いずれかの同意対象文書を変更した場合に更新する。

## 現行バージョンの評価

| 文書 | 現行 | 評価 |
|---|---:|---|
| 利用規約 | 1.9.0 | 読了と「読みたい！」作品を重複登録できない運用及び読了投稿時の自動削除を追加したためMINORと評価 |
| プライバシーポリシー | 1.8.0 | 「読みたい！」に関する取得情報、利用目的、通知及び公開範囲を追加したためMINORと評価 |
| コミュニティガイドライン | 1.3.0 | 返信にもネタバレ表示を設定するルールを追加したためMINORと評価 |
| 権利侵害・通報ポリシー | 1.2.0 | 返信単位の報告及び管理者による返信単位の対応手続を追加したためMINORと評価 |
| 外部送信に関する公表事項 | 1.8.0 | 「読みたい！」の保存、投稿別の登録情報、登録者一覧及び通知に関するSupabaseへの送信を追加したためMINORと評価 |

現時点の変更には、文書横断の新基準又は抜本的な制度変更に当たるものがないため、MAJOR `2.0.0`への更新は行わない。
